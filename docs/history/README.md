# Historical design docs (V2.0 migration era)

These documents were rescued from an **abandoned, unrelated early repository**
(`github.com/ronaldcklomp/Multimodal-Doc-Converter`, a 4-commit snapshot with no
shared history with this lineage) before that repo was retired. They are the only
content from it that did not already exist somewhere in this project or the Gitea
mirror.

They are preserved here for historical reference — they predate the current V2.x
line and may be partially superseded.

**Full cold archive:** the complete old repository (all history + committed test
data) is stored as a `git bundle` in the NAS restic backup, snapshot `97618d41`
(tags `archive`, `mm-docconverter-v1-ronaldcklomp`). Restore with
`restic restore 97618d41 --target <dir>`.

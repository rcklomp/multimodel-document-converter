================================================================================
USAGE EXAMPLES
================================================================================

1. QUICK START (Python API):
   from src.mmrag_converter.v2 import create_processor
   processor = create_processor(output_dir="./output")
   processor.process_to_jsonl("document.pdf", "output/ingestion.jsonl")

2. COMMAND LINE:
   python -m src.mmrag_converter.v2.cli process document.pdf --output-dir ./output

3. WITH FULL CONFIGURATION:
   from src.mmrag_converter.v2 import V2DocumentProcessor
   processor = V2DocumentProcessor(
       output_dir="./output",
       enable_ocr=True,
       ocr_engine="easyocr"
   )
   chunks = processor.process_document("document.pdf")
